# Vending machine

Данный прект содержит содержит UVM тестбенч для контроллера управления вендингового автомата

В папке doc содержится спецификация устройства и тест-план

Тестируемый модуль находится в папке dut, тестбенч находится в папке tb. найденные баги находятся в папке sim/bugs. Результаты тестирования находятся в sim/summary.md

Проект реализован на UVM 1.2

## Компиляция

Для работы необходимо скомпилировать файлы (именно в таком порядке):  vending_machine.sv vm_pkg.sv top.sv

Для использования кастомного report_server необходимо при компиляции добавить флаг +define+USE_CUSTOM_REPORT_SERVER
